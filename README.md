# Superstore Returns Analysis Dashboard

## Project Overview
Multi-dimensional analysis of product return patterns to identify root causes and provide actionable recommendations using Tableau dashboards and storytelling.

## Live Demo
[View the interactive dashboard on Tableau Public](https://public.tableau.com/app/profile/cynthia.villanueva5504/viz/SuperstoreReturnsAnalysis_17784552256510/Dashboard1)

## Key Findings
- **Return Rate by Category** — Technology had the highest return rate at approximately 25%, identified through multi-dimensional analysis across 7 custom worksheets.
- **Return Rate Trends** — Return rates trended upward from 2018 to 2021, peaking at over 50% in late 2021, signaling an operational issue requiring immediate attention.
- **Actionable Strategy** — Delivered a complete 8-point Tableau Story with a phased implementation plan containing immediate, short-term, and long-term action steps.

## Dashboard Features
- Geographic heat map for regional return pattern analysis
- Time-series line chart tracking return rate trends (2018–2021)
- Bar charts comparing return rates across categories and sub-categories
- Scatterplot with dynamic filters for Category, Region, and Year
- 8-slide Tableau Story synthesizing all findings into a business narrative

## Tools Used
| Tool | Purpose |

## Dataset
Superstore retail dataset — includes order data, return records, product categories, customer segments, and regional data across the United States (2018–2021).
